
# ContentFlow

A modern content management dashboard built with Vue.js.

## Overview

ContentFlow is a portfolio project designed to simulate a real-world
content management and publishing workflow. The application will
allow users to create, edit, organize, and manage website content
through a responsive dashboard.

## Project Objectives

- Strengthen Vue.js development skills.
- Build reusable and maintainable components.
- Implement content management workflows.
- Practice state management and API integration.
- Develop a professional, portfolio-ready application.

## Planned Features

- Content management dashboard
- Create, edit, and delete content
- Draft, in-review, and published statuses
- Search and filtering
- Form validation
- Data persistence
- API integration
- Responsive design

## Planned Technology Stack

- Vue 3
- Vite
- JavaScript (ES6+)
- HTML5
- CSS3
- Vue Router
- Pinia
- Git and GitHub
