# Vue Projects

Vue.js is a progressive JavaScript framework for building user interfaces, designed to be incrementally adoptable and easy to integrate with other libraries or existing projects.

- Official site: https://vuejs.org
- Documentation: https://vuejs.org/guide/introduction.html

## Getting Started

``````````bash
# Install dependencies
npm install

# Start the local dev server
npm run dev

# Build for production
npm run build
``````````
